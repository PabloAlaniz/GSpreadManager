    Referencia de API

    SheetManager

    gspreadmanager.SheetManager

    Gestor de un documento de Google Sheets (API 2.0, sin estado de pestaña mutable).

    Ejemplo

    mgr = SheetManager("MiDoc", json_google_file="creds.json") ws = mgr.worksheet("Hoja1") ws.append([["Ana", "ana@example.com"]]) ws2 = mgr.worksheet("Hoja2") # handle independiente

    __init__(doc_name=None, json_google_file=None, *, key=None, max_retries=3, retry_backoff=1.0, credentials=None, client=None, service_account_info=None, use_adc=False, backend=None, http_timeout=DEFAULT_HTTP_TIMEOUT, dataframe_backend='pandas', sheets_client=None, cache=False, cache_ttl=None, cache_max_entries=None, rate_limit=None, rate_limit_burst=None, batch_cell_limit=DEFAULT_MAX_CELLS_PER_REQUEST)

    Configura la autenticación y los servicios de aplicación.

    Indicá doc_name (abrir por nombre) o key (abrir por id de Drive). Para abrir por URL usá el classmethod :meth:open_by_url. dataframe_backend elige el motor de DataFrame ('pandas' o 'polars') para read_dataframe / write_dataframe.

    backend elige el transporte. Desde la 3.0 el default es el cliente nativo (REST propio sobre google-auth; culmina el ADR 0001), salvo que se pase client= (un cliente de gspread preautorizado). Valores: "native", "gspread" (requiere el extra pip install "GSpreadManager[gspread]") o "auto" (gspread si está instalado, si no nativo — el default de la 2.x). http_timeout (segundos, solo backend nativo) limita cada petición HTTP; None lo desactiva.

    sheets_client inyecta un ClientPort propio (ej. el backend en memoria de gspreadmanager.testing), salteando la autenticación con gspread.

    cache=True activa una caché de lecturas que se invalida con cada escritura propia (no detecta cambios de otros procesos); usá :meth:clear_cache para forzar el refresco. cache_ttl (segundos) expira las entradas y acota la ventana de staleness; cache_max_entries limita el tamaño (desalojo LRU). Pasar cualquiera de los dos activa la caché aunque no se indique cache=True.

    rate_limit (operaciones por segundo) activa un freno proactivo de cuota (token bucket); rate_limit_burst fija la ráfaga máxima (por defecto max(1, rate_limit)).

    batch_cell_limit (celdas por petición de escritura) parte automáticamente los append/batch_update/upsert grandes en varias peticiones (cada chunk con su propio retry y permiso del rate limiter); None desactiva el chunking.

    __enter__()

    Permite usar el gestor como context manager.

    __exit__(exc_type, exc_val, exc_tb)

    Salida del context manager (las operaciones se aplican de inmediato).

    open_by_key(key, json_google_file=None, **kwargs) classmethod

    Crea un gestor para el documento con key (id de Drive).

    open_by_url(url, json_google_file=None, **kwargs) classmethod

    Crea un gestor para el documento de una URL de Google Sheets.

    clear_cache()

    Invalida la caché de lecturas (no-op si se creó con cache=False).

    worksheet(tab_name=None)

    Devuelve un handle inmutable a una pestaña (la primera si tab_name es None).

    list_worksheets()

    Lista las pestañas del documento: {'sheetId', 'title', 'index', ...}.

    worksheet_by_index(index)

    Devuelve el handle de la pestaña en la posición index (0-based).

    worksheet_by_id(sheet_id)

    Devuelve el handle de la pestaña con el sheetId dado.

    create_sheet(title, rows=100, cols=26, index=None)

    Crea una nueva pestaña y devuelve su handle (sin cambiar ninguna 'hoja activa').

    delete_sheet(title)

    Elimina la pestaña con el nombre dado.

    worksheet_or_create(title, rows=100, cols=26)

    Devuelve el handle de la pestaña title, creándola si no existe.

    create_spreadsheet(title, folder_id=None)

    Crea un nuevo documento de Google Sheets.

    delete_spreadsheet(file_id)

    Elimina un documento por su ID.

    copy_spreadsheet(file_id, title=None, copy_permissions=False, folder_id=None)

    Crea una copia de un documento existente.

    list_spreadsheets(title=None, folder_id=None)

    Lista los documentos accesibles (filtrando por título/carpeta si se indica).

    update_title(title)

    Renombra el documento (updateSpreadsheetProperties).

    update_locale(locale)

    Cambia el locale del documento (ej. "es_AR").

    update_timezone(timezone)

    Cambia la zona horaria del documento (ej. "America/Argentina/Buenos_Aires").

    set_developer_metadata(key, value, visibility='DOCUMENT')

    Guarda un par clave/valor de developer metadata anclado al documento.

    list_developer_metadata()

    Lista la developer metadata del documento y de todas sus hojas.

    delete_developer_metadata(key)

    Elimina toda la developer metadata con la clave dada.

    share(email_address, role='reader', perm_type='user', notify=True, email_message=None, with_link=False, doc_name=None)

    Comparte el documento (por defecto el de este gestor) con un destinatario.

    list_permissions(doc_name=None)

    Lista los permisos del documento.

    remove_permission(value, role='any', doc_name=None)

    Quita el permiso de un usuario/grupo/dominio; devuelve los IDs eliminados.

    list_named_ranges()

    Lista los named ranges del documento.

    delete_named_range(named_range_id)

    Elimina un named range por su id (obtenido de list_named_ranges).

    export(export_format=ExportFormat.PDF)

    Exporta el documento en el formato dado (ver ExportFormat); devuelve bytes.

    WorksheetContext

    gspreadmanager.WorksheetContext

    Handle inmutable a una pestaña concreta. Todas las operaciones actúan sobre ella.

    No tiene parámetros tab_name ni efectos colaterales sobre otros handles: se obtiene con SheetManager.worksheet(name) y queda atado a esa pestaña.

    worksheet property

    Devuelve el puerto de hoja subyacente por si se necesita acceso directo.

    title property

    Nombre de la pestaña.

    __init__(worksheet, manager)

    Recibe la hoja (puerto) y el gestor que provee los servicios.

    update_cell(row, col, value)

    Actualiza una celda (índices 1-based).

    update_row(row, data, start_column=None)

    Actualiza una fila celda por celda desde start_column (o la primera).

    read(skiprows=0, output_format='list', numericise=False, render=None)

    Lee la hoja como list, dict o pandas (según output_format).

    Si numericise es True, convierte los valores a int/float cuando corresponde (no aplica al formato pandas, que infiere tipos por su cuenta). render controla cómo devuelve los valores la API: "formatted" (default), "unformatted" (números crudos) o "formula" (la fórmula en vez del valor).

    read_range(fila_start, fila_end, column_start, column_end)

    Lee un rango por índices de fila/columna; devuelve {'fila': nro, 'values': [...]}.

    append(data)

    Añade filas al final de la hoja.

    Si data supera batch_cell_limit (celdas), se parte en varios appends — cada chunk con su propio retry y permiso del rate limiter — y se devuelve la lista de respuestas.

    insert(data, fila=None)

    Inserta data en fila (o al final), validando lista de listas homogénea.

    iter_rows(page_size=1000, skiprows=0)

    Itera las filas de la hoja de a páginas de page_size (lectura perezosa).

    Pensado para hojas grandes: solo materializa una página por vez. Cada página pide su propio permiso al rate limiter y tiene su propio retry. Las filas se devuelven como vienen de la API (sin padding a un ancho uniforme).

    iter_records(page_size=1000)

    Itera las filas como dicts {columna: valor} (encabezado en la fila 1).

    iter_as(model, page_size=1000)

    Itera las filas como instancias de model (dataclass o Pydantic), de a páginas.

    import_csv(source, *, clear=True, delimiter=',')

    Vuelca un CSV en la hoja desde A1 (limpiándola antes salvo clear=False).

    source puede ser una ruta (str/Path) o un objeto file-like abierto en modo texto. Los valores se escriben en crudo (RAW), sin interpretación.

    batch_update(range_data, value_input_option=DEFAULT_VALUE_INPUT_OPTION)

    Actualiza varios rangos en una sola petición.

    Si el total supera batch_cell_limit (celdas), se parte en varias peticiones (un rango individual nunca se parte).

    upsert(rows, key)

    Actualiza por la columna clave key las filas existentes y agrega las nuevas.

    rows: dicts {columna: valor} (solo se actualizan las columnas presentes) o listas alineadas al encabezado. Devuelve {"updated": n, "appended": m}.

    upsert_models(models, key)

    Upsert de modelos tipados (dataclasses o Pydantic) por la columna clave key.

    update_where(where, updates)

    Aplica updates ({columna: valor}) a las filas que cumplen where.

    where: dict de igualdades ({"estado": "pendiente"}) o un predicado que recibe la fila como dict. Devuelve la cantidad de filas afectadas.

    delete_where(where)

    Elimina las filas que cumplen where; devuelve cuántas se borraron.

    rows_where_column_equals(column, value)

    Devuelve (nro_fila, fila) para las filas cuya columna column es value.

    last_row()

    Devuelve el índice (1-based) de la última fila con datos; 0 si está vacía.

    row_with_empty_in_column(column_letter)

    Encuentra la primera fila con celda vacía en una columna; (None, None) si no hay.

    format_range(ranges, cell_format)

    Aplica un formato a uno o más rangos.

    format_header(range_name='1:1', background_hex='#D9EAD3')

    Atajo de formato de encabezado (negrita + color de fondo).

    set_background(ranges, color)

    Aplica un color de fondo a uno o más rangos.

    set_text_format(ranges, *, bold=None, italic=None, font_size=None, color=None)

    Aplica formato de texto (negrita, itálica, tamaño, color).

    set_number_format(ranges, pattern, number_type='NUMBER')

    Aplica un formato numérico a uno o más rangos.

    freeze(rows=None, cols=None)

    Congela rows filas y/o cols columnas.

    merge(range_name, merge_type='MERGE_ALL')

    Combina las celdas de un rango.

    set_data_validation(range_name, condition_type, values=None, strict=True, show_custom_ui=True)

    Aplica una regla de validación de datos a un rango.

    add_dropdown(range_name, values, strict=True)

    Agrega un desplegable (lista de opciones) a un rango.

    add_checkbox(range_name)

    Agrega casillas de verificación (checkbox) a un rango.

    add_conditional_format(range_name, condition_type, values, cell_format, index=0)

    Agrega una regla de formato condicional booleana a un rango.

    clear(ranges=None)

    Limpia uno o más rangos, o toda la hoja si ranges es None.

    find_replace(find, replacement, *, match_case=False, match_entire_cell=False, search_by_regex=False, include_formulas=False)

    Reemplaza ocurrencias de find por replacement en esta pestaña.

    Devuelve el resumen de la API (occurrencesChanged, valuesChanged, ...). Con search_by_regex=True, find es una regex (sintaxis RE2 de Google).

    copy_to(destination_key)

    Copia esta pestaña a otro documento (por su key de Drive).

    Devuelve las propiedades de la hoja creada (sheetId, title, ...). El destino debe ser accesible con las mismas credenciales.

    find(query, case_sensitive=True)

    Busca la primera celda cuyo valor coincide con query; None si no hay.

    insert_rows(at, number=1, inherit_from_before=False)

    Inserta number filas en blanco antes de la fila at (1-based).

    insert_cols(at, number=1, inherit_from_before=False)

    Inserta number columnas en blanco antes de la columna at (1-based).

    delete_rows(start, end=None)

    Elimina las filas start..end (1-based, inclusivo); end=None borra una.

    delete_cols(start, end=None)

    Elimina las columnas start..end (1-based, inclusivo); end=None borra una.

    add_rows(number)

    Agrega number filas al final de la hoja.

    add_cols(number)

    Agrega number columnas al final de la hoja.

    resize_rows(start, end, pixels)

    Fija la altura (en píxeles) de las filas start..end (1-based, inclusivo).

    resize_cols(start, end, pixels)

    Fija el ancho (en píxeles) de las columnas start..end (1-based, inclusivo).

    hide_rows(start, end=None)

    Oculta las filas start..end (1-based, inclusivo).

    unhide_rows(start, end=None)

    Muestra las filas start..end (1-based, inclusivo).

    hide_cols(start, end=None)

    Oculta las columnas start..end (1-based, inclusivo).

    unhide_cols(start, end=None)

    Muestra las columnas start..end (1-based, inclusivo).

    update_note(cell, text)

    Fija la nota de una celda (ej. update_note("B2", "revisar")).

    clear_note(cell)

    Quita la nota de una celda.

    get_note(cell)

    Devuelve la nota de una celda (cadena vacía si no tiene).

    define_named_range(name, range_name)

    Define un named range que apunta a un rango A1 de esta hoja.

    add_protected_range(range_name, description=None, warning_only=False)

    Protege un rango A1 de esta hoja (warning_only solo advierte).

    list_protected_ranges()

    Lista los rangos protegidos de esta hoja.

    delete_protected_range(protected_range_id)

    Quita la protección de un rango por su id (de list_protected_ranges).

    sort_range(range_name, *specs)

    Ordena un rango por columnas. Cada spec es (columna_1based, 'asc'|'desc').

    set_basic_filter(range_name=None)

    Activa un filtro básico sobre un rango (o toda la hoja si range_name es None).

    clear_basic_filter()

    Quita el filtro básico de la hoja.

    unmerge(range_name)

    Deshace la combinación de celdas de un rango.

    set_tab_color(color)

    Fija el color de la pestaña.

    add_chart(chart_type, domain, series, *, title=None, anchor_cell='A1', legend='BOTTOM_LEGEND')

    Agrega un gráfico embebido y devuelve su chartId.

    chart_type: LINE, BAR, COLUMN, AREA, SCATTER o PIE. domain es el rango de etiquetas (eje X / categorías) y series los rangos de datos (PIE usa solo el primero). El gráfico se ancla en anchor_cell.

    delete_chart(chart_id)

    Elimina un gráfico embebido por su id.

    add_pivot_table(source, anchor_cell, *, rows, values, columns=None)

    Escribe una pivot table en anchor_cell a partir del rango source.

    rows/columns: offsets 0-based de columnas del rango fuente para agrupar. values: pares (offset, función) con función SUM/COUNT/COUNTA/AVERAGE/MAX/ MIN/MEDIAN.

    set_banding(range_name, *, first_color, second_color, header_color=None)

    Aplica bandas de color alternadas por fila; devuelve el bandedRangeId.

    delete_banding(banded_range_id)

    Quita las bandas alternadas por su id.

    set_developer_metadata(key, value, visibility='DOCUMENT')

    Guarda un par clave/valor de developer metadata anclado a esta pestaña.

    clear_tab_color()

    Quita el color de la pestaña.

    read_dataframe(skiprows=0, *, drop_empty_rows=False, drop_empty_cols=False, index_col=None)

    Lee la hoja como un DataFrame (backend del gestor: pandas o polars).

    drop_empty_rows/drop_empty_cols descartan filas/columnas totalmente vacías; index_col fija una columna como índice (solo pandas).

    write_dataframe(df, include_header=True, clear=True, *, start_cell=None, include_index=False)

    Escribe un DataFrame en la hoja (desde A1 o start_cell), limpiándola si clear.

    include_index vuelca también el índice como primera columna (solo pandas).

    ensure_schema(model, *, create=True, strict=False)

    Valida (o crea) el encabezado de la hoja contra el esquema de model.

    Hoja vacía: escribe el encabezado del modelo (salvo create=False). Columnas del modelo ausentes en la hoja: SchemaError con missing_columns/extra_columns. Columnas extra: se reportan (y con strict=True, fallan). Devuelve {"created": bool, "missing": [...], "extra": [...]}.

    read_as(model, skiprows=0)

    Lee la hoja como una lista de instancias de model (un @dataclass).

    El encabezado (1ª fila tras skiprows) mapea a los campos del modelo por nombre, o por field(metadata={"column": ...}). Los valores se convierten al tipo anotado.

    append_models(models)
